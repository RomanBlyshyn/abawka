# ABAWKA

Інтернет-магазин іграшок для Європи й України. Без онлайн-оплати: покупець надсилає заявку з кошика, вона приходить власнику в Telegram, далі власник зв'язується сам. 9 мов, 4 валюти, адмінка з ролями. Сайт після запуску передається замовнику.

Вимоги — [ТЗ.md](ТЗ.md), етапи й статус — [PLAN.md](PLAN.md). Перед роботою над етапом звірся з обома.

## Стек
- Astro 7 (статична збірка) + TypeScript strict
- Supabase: Postgres, Auth, RLS, Storage, Edge Functions (регіон EU)
- Netlify (хостинг, build hook на зміни в адмінці)
- Telegram Bot API (сповіщення про заявки)
- Playwright (e2e і скріншоти)

## Запуск
- Встановити: `npm install`
- Секрети: скопіювати `.env.example` → `.env`, заповнити.
- Розробка: `npm run dev` → http://localhost:4321/
- Перевірка типів: `npm run check`; перекладів: `npm run check:i18n`; збірка: `npm run build`
- E2E-тести: `npm run test:e2e` (самі збирають сайт і піднімають preview на 4322). Перед запуском зупинити інші preview: на Windows вони тримають файли в `dist/` і збірка падає.

## Структура
- `src/pages/[lang]/` — сторінки, по одній копії на кожну з 9 мов
- `src/pages/index.astro` — корінь, перенаправляє на мову з браузера
- `src/i18n/` — `config.ts` (мови), `<мова>.json` (тексти інтерфейсу), `index.ts` (`useTranslations`)
- `src/layouts/`, `src/components/` — верстка
- `src/data/` — локальні дані до підключення бази
- `supabase/` — міграції, Edge Functions
- `docs/brand/` — лого від клієнта; `docs/` — скріншоти для README

## Правила проєкту
- Тексти інтерфейсу тільки через `t('ключ')`, ніколи не писати їх прямо в розмітці.
- Усі 9 мов обов'язкові: новий ключ одразу додавати в кожен `src/i18n/<мова>.json`, множину — формами `.one/.few/.many/.other`. Перед комітом `npm run check:i18n`.
- Ціни — цілі числа в мінорних одиницях базової валюти, без float.
- Суму, знижки, промокод і наявність рахує сервер, а не браузер.
- Форми: при помилці «не надіслано, спробуйте ще раз», введене не зникає; валідація і в браузері, і в базі.
- Кожен етап закінчується перевіркою з PLAN.md; візуальні етапи показувати Роману до переходу далі.
- Кожен знайдений баг — одразу тест у `tests/e2e/`, щоб не повернувся. Перед комітом: `check`, `check:i18n`, `test:e2e`.
- Dev/preview-сервер зупиняти за PID порту, ніколи не вбивати всі node.exe.
